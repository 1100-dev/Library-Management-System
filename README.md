#  Library Management System (C# WinForms + SQL Server)

##  Overview
This is a Desktop Library Management System built using **C# Windows Forms** and **Microsoft SQL Server**.  
It helps manage students, books, issue/return operations, and maintains library records efficiently.

---

## Features

- 👤 Add / Update / Delete Students
- 📖 Add / Manage Books
- 📥 Issue Books to Students
- 📤 Return Books with date tracking
- 🔍 Search Students by Enrollment
- 🔍 Search Books by Name
- 📊 View issued and returned book records
- 🗄️ SQL Server database integration

---

##  Tech Stack

- Language: C#
- Framework: .NET Windows Forms (WinForms)
- Database: Microsoft SQL Server
- IDE: Visual Studio

---

## 🚀 How to Run

1. Open project in **Visual Studio**
2. Restore NuGet packages if needed
3. Update SQL connection string in `App.config` or code:
4. data source=YOUR_SERVER; database=library; integrated security=true
5. 4. Build Solution
6. Run Project (F5)
7. Add username as "Rabia" and Password as "pass".
---

## Notes

- Make sure SQL Server is running
- Database name must match: `library`
- `.vs`, `bin`, and `obj` folders are ignored in Git
